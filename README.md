# projetoTI
Projeto Final da Disciplina de Tecnologias da Internet. Desenvolvemos um site sobre o jogo Dark Souls 3. Para as cores e a estilização geral do site, nos baseamos no estilo visual do próprio jogo e também nos inspiramos em um site de fãs, a Dark Souls 3 Wiki, de onde retiramos algumas informações.
A nossa ideia foi criar um site informativo sobre o jogo, parecido com a wiki, porém mais direto ao ponto, fácil de utilizar e com a informação apresentada de forma mais organizada para o utilizador.
